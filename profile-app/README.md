Profile App
===========

React + TypeScript single-page app for User Profile sections:

- Accounting Settings
- Terms & Services
- Rate Us
- Help & Support

Scripts
-------

- `npm install`
- `npm run dev` - start dev server
- `npm run build` - build for production
- `npm run preview` - preview production build

Notes
-----

- Data is stored in `localStorage` only.
- Routing uses `react-router-dom@6`.
